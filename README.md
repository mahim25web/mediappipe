# MediaPipe Web Application

A lightweight web-based project utilizing **Google MediaPipe** for real-time computer vision and tracking directly in the browser. 

Live Demo: [mahim25web.github.io/mediappipe/](https://mahim25web.github.io/mediappipe/)

---

## 🚀 Features

- **Real-Time Detection:** Processes video input directly from the browser webcam.
- **Client-Side Processing:** Powered by JavaScript and Google MediaPipe for fast, low-latency performance without needing a backend server.
- **Lightweight & Responsive:** Clean HTML5, CSS3, and modern JS UI layout.

---

## 🛠️ Built With

* [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) – Page structure and canvas element rendering.
* [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) – Styling and layout.
* [JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript) – Application logic and MediaPipe API integration.
* [Google MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/guide) – Cross-platform ML framework for computer vision.
